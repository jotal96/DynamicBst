# Dynamic Binary Search Tree (Java)

This project implements a **dynamic Binary Search Tree (BST)** in Java, designed for efficient insertions, deletions, and searches.

While the structure was initially developed within the context of a **Spring-based application**, the core functionality is entirely **decoupled from web or framework-specific dependencies**.
## Features

- Generic node-based implementation
- Dynamic insertion and deletion
- Search functionality
- Easy to integrate into other Java projects

## Getting Started

### Requirements

- Java 11 or higher
- Maven or Gradle (if using with Spring)
- No external dependencies required for BST logic
